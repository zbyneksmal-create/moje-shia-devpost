Follow one plan through the code.

Select an area, match movements, create a link, open the client view. These are the actual function names in app.js.

1. A therapist selects Neck

choose('neck') updates an in-memory Set. renderTherapist() refreshes the body map, pressed buttons and preview.

2. The two neck movements appear

matches(ordered()) reads the fixed MOVEMENTS catalogue. This is a deterministic lookup, not an AI diagnosis.

3. A QR and a link describe the same plan

clientUrl() encodes only allowlisted area keys. renderHandover() hands this URL to the bundled QRCode library and the copy button.

4. The client opens the plan

validAreas() discards unknown inputs; renderClient() reads the same catalogue and displays instructions and stop conditions.

A practice to reuse

Trace one visible action all the way to its result. Checking selection, serialized URL and receiving view is more useful than checking only whether a page opens.
